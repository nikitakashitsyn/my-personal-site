# Мой персональный сайт

Персональный сайт-портфолио, созданный в рамках изучения веб-разработки.

## О проекте

На сайте представлена информация обо мне, моих интересах, целях и планах на будущее.

Разделы сайта:

* Обо мне
* Что я читаю
* Мои цели
* Мои мечты
* Контактная информация

##Используемые технологии

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* GitHub Pages

## Запуск проекта

Клонировать репозиторий:

```bash
git clone https://github.com/nikitakashitsyn/my-personal-site.git
```

Перейти в директорию проекта:

```bash
cd my-personal-site
```

Открыть файл `index.html` в браузере.
